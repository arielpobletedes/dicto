# ProTouchTyping

## Resúmen

Es una aplicación para aprender y mejorar la dactilografía con ejercicios de distinto nivel. Debe considerar carcteres especiales pues está pensada para programadores. Los usuarios podrán darse de alta y acceder a ciertos ejercicios básicos. El resto de ejercicios estará sujeto a pago.

## Stack tecnológico

- Debe ser un Monorepo.
- Con estrustura de proyecto moderna y profesional.
- Todo con TypeScript
- Con TailWind CSS
- Frontend en React
- Backend en Next.js
- Base de datos postgresql en la plataforma Neon.
- Full Auth, con roles iniciales de Administrador y estudiante.
- COnsiderar Drizzle, Zod y Concurrently
